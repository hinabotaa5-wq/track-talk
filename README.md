# TRACK TALK

陸上競技のファン・選手・指導者が、大会・記録・レースについて匿名で語り合い、クラブチームの仲間や練習相手を見つけられるコミュニティ（MVP）です。都道府県陸協と国際大会の日程は自動で取り込み、月ごとの大会一覧として表示します。

## サービスの内容

陸上競技について語り合う、匿名のコミュニティです。自己紹介の欄はありません。ニックネーム（10文字まで）は任意で、マイページで「投稿にニックネームを公開する」をオンにした人だけ、投稿の詳細に表示されます（既定は非公開で、コメントには出ません）。ニックネームは、管理者が通報やお問い合わせを見るときにも使われます。スマホで使う前提の画面で、下部のタブ（ホーム／大会／コーチ／ケガ／マイページ）から各機能へ移動します。PC では同じタブがヘッダーに並びます。投稿は、ホームの右下の「＋」ボタンから始めます。

### ログイン

- メールアドレスとパスワード（8文字以上）、または Google アカウントで登録・ログインします（Supabase Auth）。メール登録では確認メールが届きます。パスワード再設定もできます。
- ログインしなくても、ホームの投稿一覧・投稿の詳細・コメントは見られます。投稿・大会一覧・マイページ・いいね・保存・コメント・通報にはログインが必要です。

### ホーム（`/`）

- 投稿をカードで並べます（スマホ2列、PC 3〜4列、20件ずつ）。
- 並び替え: **人気**（直近14日の投稿をいいね数順）／**新しい順**／**募集**（クラブチーム募集だけ）／**レビュー**（シューズ・スパイクの商品一覧）／**保存**（自分が保存した投稿）
- キーワード検索: タイトル・本文・募集の各項目を部分一致で探します。都道府県名を入れると、その県を活動場所にした募集も見つかります。
- 右下の「＋」ボタンで投稿（`/upload`）を開きます。

### コーチ（`/coaching`）

- オンラインコーチングは準備中で、機能そのものはまだありません。このタブでは、動画添削（最初に始める）とパーソナル指導（あとで始める）がどういうものかの説明と、「コーチを募集しています」の告知だけを出します。ログインしなくても見られます。
- 「応募する」で応募画面（`/coach/apply`、ログインが必要）を開きます。入れるのは、枠（コーチ／先輩）、担当種目（100m〜10000m、ハードル3種、3000m障害物、跳躍4種、投擲4種、競歩、リレーの21種目から複数）、記録、成績、競技年数だけです。
- 応募は管理者画面の「コーチ」タブに届き、運営が承認か見送りにします。結果は応募画面に出て、通知を設定していれば Web プッシュでも届きます。審査中は書き直せ、見送りになったら出し直せます。承認された後は変えられません。
- 承認されたコーチは、コーチ画面（`/coach`）で「受付中」と1日に受ける上限（1〜20本、初期値5本）を切り替えます。受けた★の平均と件数もここに出ます。依頼は通知で届くので、通知を受け取れる端末がないと受付中にはできません。
- フォーム添削は、決済ができるまでデモ版です。管理者画面の「コーチ」タブで招待コード（8文字、1人1回）を作って渡し、受け取った人が `/coaching/new` で入れると依頼を送れるようになります。
- 依頼では、枠（コーチ／先輩）、種目（最初は100mだけ。コーチが増えしだい種目を増やします）、見てほしい点（選択式、自由記述なし）、動画（30秒まで、非公開でアップロード）を選びます。生まれた年月の登録が必要で、18歳未満は保護者の同意が済むまで2本目を送れません。同意しないと言われたら送れません。送る画面に返ってくる目安が出ます。目安はいつ送っても翌日の12時（夜に送れば翌日の昼まで）で、目安までに返ってこない依頼は期限切れになります。
- 依頼は、枠と種目が合う受付中のコーチのうち、最後に打診されたのが一番古い人に回ります（同じ依頼を同じ人には二度回さない。1人が同時に持てるのは2本まで、1日の上限本数まで。★の評価が5件以上あって平均が★3未満のコーチには回しません）。コーチには Web プッシュとベルの通知が届き、コーチ画面で30分以内に「引き受ける」か「見送る」を選びます。見送りや時間切れなら次の人に回り、回せる人がいなければ待ちのまま、誰かが受付を始めたときに回ります。動画は引き受けたあとにだけ見られます。
- 30分の打診切れと返却目安切れは、Cloud Scheduler が1分ごとに呼ぶ `POST /internal/coaching/tick` が片付けます（設定は [docs/cloud-run-deploy.md](docs/cloud-run-deploy.md) の「フォーム添削の tick」）。期限切れになった依頼は、依頼した人に通知が届きます。
- 引き受けたコーチは、コーチ画面から依頼を開いて返答を書きます。形式は、良い点1つ、直す点1〜2つ、おすすめのドリル1つ（各300文字まで）と、任意の見本動画（30秒まで）です。URL・メールアドレス・電話番号・SNS の名前や ID など、連絡先らしき文字列があると送れません。返却の目安を過ぎると返答できません。
- 送った依頼は `/me/coaching/requests` に並び、返答は依頼の画面で読めます。返答と一緒に、見てくれたコーチのプロフィール（ニックネーム・枠・担当種目・記録・成績・競技年数）が届きます。取り消しはできません。利用者は★で評価し（つけ直せる）、「ここがわからなかった」（用語／ドリルのやり方／直す点の意味／その他）を1回だけ押せます。押すとコーチに通知が届き、コーチは補足を1回だけ返せます（300文字まで）。やりとりはコーチから利用者への一方通行で、自由に書ける欄はありません。
- 返却から7日たつと、tick が「アドバイスは役に立ちましたか」（役に立った／少し／役に立たなかった）を通知で聞きます。
- 利用者は返答を通報できます。管理者画面の「通報」から返答を非表示にでき、「コーチ」タブでは各コーチの最初の20本の返答（試用期間）を読んで非表示にできます。

### レビュー（`/?sort=review`、`/reviews/[id]`）

- シューズ／スパイクの2択で商品カードを並べます（レビュー数・平均★の順）。カードを選ぶと商品詳細に入り、その商品のレビュー（★1〜5＋コメント2000字まで）を見られます。見るだけならログイン不要です。
- 投稿はログインが必要で、1商品につき1人1件です。自分のレビューは削除できます（書き直すときは削除してから）。
- 商品は管理者が登録します（マイグレーション `000031` の初期データと、管理者画面 `/admin` の「商品」タブ）。

### 投稿（`/upload`）

投稿の種類は5つです（ケガの投稿は「ケガ」タブから行います。下の「ケガ」を参照）。

| 種類 | 内容 | 主なルール |
| --- | --- | --- |
| 文章 | タイトル・本文・写真のいずれかでスレッドを立てる | タイトル120字・本文10000字まで。写真は1枚（10MB まで。送る前にブラウザで長辺2048pxに縮める） |
| YouTube の URL(ショート動画も可) | 動画を引用してスレッドを作る | タイトルとサムネイルは YouTube から取得。1つの動画につきスレッドは1つで、既にあればそのスレッドを開く |
| 自分の動画 | 撮った動画をアップロード | 100MB まで。Cloudinary へブラウザから直接アップロードし、保存時に720p相当（長辺1280px）へ縮める |
| クラブチームの募集 | チームのメンバーを募る | チーム名・活動場所（都道府県を1つ以上＋詳細）・活動時間・男女比・平均年齢・募集年齢・SNS の URL（https、4件まで）・写真（1枚まで）・詳細。通知は飛ばず、募集タブに出る |
| 練習相手募集 | 一緒に練習する相手を募る | 練習場所・日時（未来のみ）・種目（100m〜十種競技、リレー、その他）・募集人数（1〜99人）・詳細（2000字まで） |

自分の投稿は編集・削除できます。削除した投稿や、募集の編集で外した写真は、ほかの投稿で使われていなければ Cloudinary からも消します。他の人の投稿には、いいね・保存・コメント（2000字まで）・通報ができます。自分のコメントも編集・削除できます。

### 練習相手募集の流れ

1. 募集者が練習の日時・場所・種目・人数を投稿する
2. 参加したい人が「参加したい」で申請する → 募集者に通知
3. 募集者が申請を **承認** か **見送り** にする → 承認された人に通知。承認数が定員に達すると「満員」になる
4. 練習が終わったら募集者が **解散** する → 承認された参加者がいれば、募集者と参加者の全員に「評価しあってください」の通知
5. 解散後、募集者と参加者がお互いを **良い／普通／悪い** と、ひとこと（200字まで）で評価する。評価は1回だけで、あとから変えられない
6. 評価は募集者の「これまでの評価」として、練習の投稿に表示される

満員か解散の後は、募集者と承認された参加者だけがコメントできます（他の人はコメントを見るだけ）。

### ケガ（`/injury`）

怪我で走れない人が、同じケガのグループに集まって、気持ちの吐き出しや経過を分け合うタブです。ここの投稿はホームのフィードには出ません（自分の投稿一覧と保存一覧には出ます）。

- `/injury` はケガごとのグループの一覧です。グループはハムストリングの肉離れ・太もも前の肉離れ・捻挫・アキレス腱炎・ジャンパー膝(膝蓋腱炎)・シンスプリント・肩の痛み・肘の痛みの8つと「その他」です。各グループの人数と、参加中ならいまの段階が出ます。未参加のグループをタップすると、重さ・病院でみてもらったか・ケガをした月・場所・そのとき何をしていたか・ケガの前に変わったこと(複数可)・種目・いまの段階を1問ずつ選んで答え、答え終えると入れます。「その他」では最初にケガの名前も書きます。
- グループの中（`/injury/{ケガ}`）は、怪我直後からゴール（大会に復帰）まで、矢印でつないだロードマップです。段階（安静中／リハビリ中／ジョグ再開／練習に復帰／大会に復帰）ごとに人数とアバターが集まり、タップするとその段階の投稿を読めます。
- グループの閲覧と投稿は、参加した人だけです。投稿できるのは自分のいまの段階だけで、ほかの段階は読むだけです。投稿は、グループの中の「投稿」から書きます（`POST /v1/injury/groups/{ケガ}/posts`）。投稿の詳細・コメント・「わかる」・保存も、投稿者か同じケガの参加者、管理者だけが使えます（参加していないと 403、ログインしていないと 401）。公開のフィード（`/v1/posts?kind=injury`）はありません。
- 段階は「段階を変える」から、前にも後ろにも、飛ばしても変えられます。書いた投稿は、書いた時点の段階のまま残ります。初めて「大会に復帰」に着いたときだけ、紙吹雪とメッセージで祝います（端末ごとに1回）。段階を変えている間は「変更しています…」と出ます。グループの下の「このグループを抜ける」で抜けられます（段階の記録は消え、グループの中は読めなくなります。書いた投稿は残り、あとでもう一度入れます。`DELETE /v1/injury/groups/{ケガ}/me`）。
- いいねは「わかる」と表示されます。
- 投稿者は、その後の経過を時系列で追加・編集・削除できます（1投稿50件、1件2000字まで）。編集しても報告の日時は変わらず、通知も送りません。最新の段階がカードと詳細のバッジに出ます。投稿の段階は、経過の報告があればその最新の段階、なければ書いた時点の段階です。
- **みんなの復帰データ**（`/injury/stats`）で、ケガごとの投稿数と、各段階に報告した人数・投稿から最初の報告までの日数の中央値を匿名で見られます。報告が5人そろった段階だけ日数を表示します（ログイン不要）。
- ケガの投稿の詳細には、同じケガの「復帰の目安」（日数の中央値が出ている段階だけ）を表示します。

### エグ練大会（`/menu-contest`）

- 冬（11月〜3月）は大会が少ないので、2週間ごとに「その回で一番エグかった練習」を集めて1位を決めます。シーズンは11月の最初の月曜に始まり、応募の締め切りが3月31日の終わりを過ぎない回まで、毎年自動で開きます。
- 1週目の月曜〜2週目の水曜が応募（1人1件、200文字まで、締め切りまで書き直し・取り消し可）、2週目の木曜に運営がトップ3を選び、金〜日が投票（1人1票、入れ直し可、自分の応募には入れられない）、翌週の月曜に結果を出して次の回が始まります。同票なら全員1位です。
- 開催中は、ホームのヘッダーの下段に、いまの段階と締め切りまでの残り時間（日・時間・分）を出します。残り24時間を切ると赤くなります。
- 応募は運営だけが読みます。管理者画面の「エグ練」タブで応募を読み、締め切り後に1〜3件を選びます。投票が1票でも入ると選び直せません。公開するのはトップ3だけで、ニックネームは公開設定の人だけ出します。

### 大会（`/competitions`）

- 月と地域（47都道府県または「国際」）を選んで、その月の大会を一覧にします。初期表示は今月（日本時間）です。最後に選んだ地域はブラウザに保存され、次回も同じ地域で開きます。
- 各大会には日程・会場と、主催者のページ（都道府県は「要項」、国際大会は「公式サイト」）へのリンクがあります。
- 一覧の上のボタンから、次の2つの専用ページを開けます。
  - **国内主要大会**（`/competitions/major-domestic`）: 日本陸連・日本学生陸上競技連合のページから取り込んだ主要16大会の日程・会場・公式サイト。日程が無い大会は「日程未定」、終わった大会は「終了」と表示します。
  - **今後の世界陸上・オリンピック**（`/competitions/major-hosts`）: 開催地（都市・会場・日程、Wikimedia Commons の写真）。
- データは自動で取り込んでいます（下の「大会データの取り込み」）。

### 通知

ヘッダーのベルに未読数が出ます。通知の種類は次の5つです。開くと既読になり、「すべて既読」もできます。

- 自分の投稿へのコメント
- 練習への参加申請（募集者へ）
- 参加の承認（申請した人へ）
- 練習の解散と評価のお願い（募集者と参加者へ）
- ケガの投稿の経過報告（その投稿に「わかる」か保存をした人へ。自分の報告は対象外で、未読の通知がある間は重ねて送りません）

### マイページ（`/me`）

- 上に「いまのケガ」（参加中のときだけ）と感覚メモのカード、その下にメニューを次の順で並べます: 自分の投稿・保存した投稿・自分のケガ履歴・ニックネームの変更・ホーム画面に追加して使う（ホーム画面から開いていないときだけ）・お問い合わせ・ガイドライン・利用規約・プライバシーポリシー・ログアウト・退会
- 自分の投稿（`/me/posts`）: 一覧（人気順／新しい順の切り替え）
- 自分のケガ履歴（`/me/injury`）: ケガの投稿を新しい順に、ケガ・日付と、経過を報告した段階ごとの日数（投稿から最初の報告まで）で振り返れます。同じケガが複数あれば知らせます。自分にしか見えません
- 感覚メモ（マイページの上と `/me/sense`）: 練習で体を動かして感じた感覚を、300字までのひとことで書き溜めます（練習メニューではなく感覚を書く場所）。種目は任意で、練習相手募集と同じ種目から選びます。1日20件まで書けます。書くと「今日も頑張ったね」と出て、ビンに粒が1つ落ちます（30粒で1杯）。たまった数・連続日数・書いた日数を表示し、過去のメモは日付ごとに新しい順で一覧・編集・削除できます。自分にしか見えず、投稿やフィードには出ません（`/v1/me/sense-notes`）
- ニックネームの変更と、投稿への公開のオン・オフ（`/me/profile`）
- お問い合わせ（種類: 不具合／アカウント／機能の要望／その他）と送信履歴
- ガイドライン・利用規約・プライバシーポリシー
- ログアウト
- 退会: 確認のため「退会する」と入力すると、自分の投稿・感覚メモ・コメント・いいね・保存・通知・練習への参加と評価・お問い合わせ・通報、そしてログイン用のアカウントが削除されます

### 安全のための仕組み

- コミュニティガイドライン（`/guidelines`）で、誹謗中傷・権利侵害・個人を特定する情報・練習会の悪用などを禁止しています。
- 投稿とコメントは、理由（スパム／嫌がらせ／誤情報／その他）を選んで通報できます。
- 管理者（`profiles.is_admin = true`）は、通報と問い合わせの一覧を見て、投稿やコメントを非表示にできます。管理者画面（`/admin`）では通報・「なんでも書いてね」・お問い合わせを一覧で見られます。非表示の操作は API（`/v1/admin/...`）で行います。
- API は接続元ごとに回数を制限しています（書き込みは1分に30回、通報とお問い合わせはそれぞれ1時間に10回まで）。
- アクセス数は Umami で計測しています。

## 構成

| 場所 | 役割 | 技術 |
| --- | --- | --- |
| `apps/web` | 画面・ルーティング | Next.js 16 / React 19 / TypeScript / Tailwind CSS 4 / Zod |
| `apps/api` | 業務ロジック・認可（`/v1`） | Go 1.25 / chi / pgx / sqlc / golang-migrate |
| PostgreSQL + Supabase Auth | DB・認証 | マイグレーションは `apps/api/migrations` |
| Cloudinary | 画像・動画の保存 | API が署名を発行し、ブラウザから直接アップロード |
| Gemini API | 都道府県の大会日程ページから大会を抽出 | `apps/api/internal/competitions` |

業務ロジックは Go API に集約しています。Next.js から PostgREST でテーブルを直接操作しません（全テーブルで RLS 有効）。

```
apps/
  api/
    cmd/api/                 API サーバー
    cmd/migrate/             マイグレーション
    cmd/importcompetitions/  大会日程の取り込み
    cmd/importmajors/        五輪・世界陸上の開催地の取り込み
    cmd/importdomestic/      国内主要大会の取り込み
    internal/                auth, cloudinary, competitions, config, db, httpx, migrate
    migrations/  queries/    SQL（queries は sqlc 用）
  web/
    app/  components/  lib/  e2e/  emails/
docs/launch.md               公開チェックリスト
```

## ローカル起動

必要なもの: Go 1.25、Node.js 22、Docker（PostgreSQL 用）

```bash
cp .env.example .env
# .env に Supabase の URL / anon key / JWT secret（必要なら Cloudinary）を入れる
make db            # docker の PostgreSQL を 127.0.0.1:55432 で起動(開発用。本番の Supabase には接続しない)
make migrate
make api        # http://localhost:8080/health
# 別ターミナル
cd apps/web && npm install && cd ../..
make web        # http://localhost:3000
```

SQL を変更したら `make sqlc` でコードを再生成します（sqlc が必要）。

## 環境変数

`.env.example` が雛形です。API はリポジトリ直下の `.env` も読み込みます。

| 変数 | 使う場所 | 説明 |
| --- | --- | --- |
| `DATABASE_URL` | API・取り込み | PostgreSQL の接続文字列（必須） |
| `SUPABASE_URL` / `SUPABASE_JWT_SECRET` / `SUPABASE_JWT_AUD` | API | JWT の検証（URL か secret のどちらかが必須） |
| `SUPABASE_SERVICE_ROLE_KEY` | API | 退会時に Auth ユーザーを削除する |
| `CLOUDINARY_CLOUD_NAME` / `CLOUDINARY_API_KEY` / `CLOUDINARY_API_SECRET` | API | アップロード署名 |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | API | フォーム添削の Web Push 通知（空なら通知は送らない）。`VAPID_SUBJECT` は `mailto:` の連絡先 |
| `COACHING_TICK_SECRET` | API | Cloud Scheduler が `POST /internal/coaching/tick` を呼ぶときに `X-Coaching-Tick-Secret` ヘッダーで送る値（空なら tick は使えない） |
| `API_ADDR` / `CORS_ORIGINS` / `LOG_LEVEL` | API | 既定は `:8080` / `http://localhost:3000` / `info` |
| `GEMINI_API_KEY` | 大会取り込み | 都道府県の取り込みに必要 |
| `GEMINI_DAILY_REQUESTS` | 大会取り込み | 1回の実行で使う Gemini リクエストの上限（既定 15） |
| `NEXT_PUBLIC_API_BASE_URL` / `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` / `NEXT_PUBLIC_SITE_URL` | Web | ブラウザに公開される値 |

フロントに置くのは `NEXT_PUBLIC_*` と **anon key のみ**です。`service_role`・`DATABASE_URL`・Cloudinary の secret・Gemini のキーは API／ホスティング／GitHub Secrets の秘密領域だけに置いてください。

## 大会データの取り込み

`apps/api` で実行します。

```bash
go run ./cmd/importcompetitions                           # 期限切れの国際大会と都道府県を取り込む
go run ./cmd/importcompetitions -prefecture 13            # 指定した県だけ（00 は国際大会）
go run ./cmd/importcompetitions -prefecture 46 -dry-run   # DB に書かずに結果を表示
go run ./cmd/importcompetitions -prefecture 46 -dry-run -url https://example.com/schedule  # 未登録のページを試す
go run ./cmd/importmajors                                 # 五輪・世界陸上の開催地
go run ./cmd/importdomestic                               # 国内主要大会（-dry-run で DB に書かず表示）
```

- **都道府県**: `internal/competitions/sources.go` に登録した各陸協の日程ページ（一部は PDF）を取得し、表を抜き出して Gemini で大会情報に変換します。前回から 10 日経った県が対象で、古い順に Gemini の上限（`GEMINI_DAILY_REQUESTS`）に収まるところまで処理します。収まらなかった県は次回に回ります。
- **国際大会**: World Athletics と Diamond League のカレンダーから Gemini を使わずに取り込みます。7 日ごとに更新します。
- **五輪・世界陸上の開催地**: Wikipedia から取り込みます。
- **国内主要大会**: 日本陸連の一覧・詳細ページと、日本学生陸上競技連合の学連別ページから取り込みます（Gemini は使いません）。取り込める大会が無いときは前回のデータを残します。

CI（`.github/workflows/ci.yml`）は push／PR ごとに API テスト（PostgreSQL サービスコンテナ付き）、Web の Lint・単体テスト・型チェック、ログインから文章投稿までの E2E を実行します。その E2E が落ちると CI が失敗します。

## デプロイ

- **API**: Cloud Run（東京）。マージしても自動ではデプロイしない。GitHub の Actions →「Deploy API」→ Run workflow で `main` をデプロイする（`.github/workflows/deploy-api.yml`）。予算を超えると自動で API を止める。初回の作り方は [docs/cloud-run-deploy.md](docs/cloud-run-deploy.md)。
- **Web**: Vercel（`apps/web`、Netlify へ移行予定）。マージしても自動ではデプロイしない（`apps/web/vercel.json`、`netlify.toml` の `ignore`）。Actions →「Deploy Web」→ Run workflow で、Secrets の `NETLIFY_BUILD_HOOK`・`VERCEL_DEPLOY_HOOK` に登録したフックを呼んで本番に出す。
- **DB / Auth**: Supabase

公開前の確認事項は [docs/launch.md](docs/launch.md) を参照してください。料金・無料枠・商用条件は変わるため、公開直前に各公式ドキュメントで確認してください。

## 管理者

`profiles.is_admin = true` を SQL で自分のユーザーに設定すると、管理者画面（`/admin`）と管理用 API を使えます。マイページにはリンクを出さないので、URL を直接開きます。画面は一覧の閲覧用で、非表示の操作は API で行います。

| API | 内容 |
| --- | --- |
| `GET /v1/admin/reports` | 通報の一覧 |
| `GET /v1/admin/inquiries` | お問い合わせの一覧（`?source=feedback` でヘッダーの「なんでも書いてね」だけに絞る） |
| `POST /v1/admin/posts/{id}/hide` | 投稿を非表示にする |
| `POST /v1/admin/comments/{id}/hide` | コメントを非表示にする |
