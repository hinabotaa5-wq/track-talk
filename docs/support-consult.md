# 大会までプランの無料相談

大会までプランは、コーチが期間・価格を決めて出品する形ではなく、選手がコーチに**無料で相談してから**始まります。対面プランと動画添削には影響しません。

## 流れ

1. コーチが「相談の受付設定」（プラン管理）で、受付中か、担当する種目、相談で聞きたいこと・サポートできる内容、価格の目安（任意）を設定します。
2. 選手がコーチ詳細の「無料相談をする」から、構造化フォームで相談を送ります。支払いもカード情報の入力もありません。
3. コーチは **48時間以内** に提案か辞退を返します。フォームの回答だけでは分からないときは、フォーム形式で聞き直せます（1つの相談に3回まで。選手の答えが届いたら48時間を数え直す）。チャットにはしません。
4. 提案には、期間（開始日〜目標大会の日）、通話、価格（運営手数料20%を引いたコーチの受け取りも表示）、提案の有効期限、内容欄の標準形が入ります。提案を出すことが、コーチ側の契約への同意（通報時の運営の閲覧・連絡先の自動検出）です。報酬の受け取り口座が未登録のコーチは提案を出せません。
5. **大人の選手**が提案を受けて申し込むと、その場で契約ができます。コーチの再引受は挟まず、お支払いが済んだ時点で始まります（支払いのないデモ版は申し込みでそのまま開始）。契約の中身は提案の写しで、終了日は目標大会の日です。
6. **未成年の選手**は、自分では申し込めません（契約レコードもできません）。「保護者に提案を送る」だけができ、保護者のリンクのページに提案が出ます。保護者が内容を確認して同意し、カードでお支払いをした時点で契約が成立します。コーチの再引受は挟みません。保護者が同意しなければ、契約も費用も生まれず、相談は「取り下げ」として終わります。保護者が事前の同意（リンクの同意）を済ませていないと、保護者に送れません。
7. 申し込まなければ、そのまま終了します。契約も費用も生まれません。

進行中の相談や契約がないコーチには、次の大会向けにもう一度相談できます（回数制限なし）。新しい大会は、新しい相談・提案・契約として扱い、未成年は契約のたびに保護者の同意とお支払いを経ます。

## サポートの内容（標準形）

提案の内容欄には、次の標準形が必ず入り、契約の説明にも写されます。回数や形式を提案ごとに選ぶ項目はありません。

> 動画への返答は、期間中は回数の制限なく受けられます。メニューはコーチが先に作り、必要に応じて見直します。

- 大会までプランに**追加相談**（別料金）はありません。大会までプランの設定で追加相談の料金は付けられず、この契約での追加相談の購入もできません（既存の値が残っていても購入は止まります）。対面プランと動画添削は従来どおりです。
- 契約の動画添削の回数（`video_reviews`）は 0（回数を決めない）として扱います。
- **未提供分の返金は期間の日割り**（第10弾）です。契約価格 ÷ 期間日数 × 未経過日数。期間日数は、実際に始まった日〜目標大会の日（日本時間の日付・両端を含む）、返金を決める日は経過した日に数え、円未満は切り捨てです（従来の按分と同じ切り捨て）。始まっていない契約は全額、期間が終わっていれば0円です。通話や動画の回数は数えません（通話分を別枠にしません）。動画の回数が決まっている従来の大会サポート、(1) 動画添削、対面プランは従来の按分のままです。

## 受け入れ状況

人数の上限（受け入れ枠）は置きません。受け入れ状況は、コーチが「相談の受付設定」で手で切り替える**「受付中／受付停止中」だけ**です。対応可能カレンダーとは連動しません。

- 受付停止中 → 選手側に「受付停止中」。新しい相談は送れません（進行中の相談と契約はそのまま続きます）。
- 再開の目安の日付は出しません。
- 契約件数や残り枠は、選手側に表示しません。
- 対面プランの受付状況をカレンダーから自動で決める仕組みは、この機能の範囲外です。

## API

| メソッド・パス | 内容 |
| --- | --- |
| `GET /v1/coaches/{id}/support-consult` | 公開の入口と受け入れ状況。受け付けていなければ `consult: null` |
| `GET/PUT /v1/coach/me/support-consult` | 受付設定（コーチ本人） |
| `GET /v1/coach/me/support-consults` | 届いた相談（コーチ本人） |
| `POST /v1/support-consults` | 相談を送る（選手） |
| `GET /v1/me/support-consults` | 自分が送った相談 |
| `GET /v1/support-consults/{id}` | 相談の詳細（当事者のみ） |
| `POST /v1/support-consults/{id}/answer` | 聞き直しへの答え（選手） |
| `POST /v1/support-consults/{id}/withdraw` | 取り下げ（選手） |
| `POST /v1/support-consults/{id}/accept` | 提案を受けて申し込む（大人の選手）。契約ができる。未成年は 409 |
| `POST /v1/support-consults/{id}/send-to-guardian` | 提案を保護者に送る（未成年の選手）。契約はできない |
| `GET /v1/guardian/{token}/support-consults[/{id}]` | 保護者のページに出す、子に届いた提案 |
| `POST /v1/guardian/{token}/support-consults/{id}/consent` | 保護者が同意して申し込む。契約ができ、支払い画面へ進む |
| `POST /v1/guardian/{token}/support-consults/{id}/decline` | 保護者が同意しない |
| `POST /v1/support-consults/{id}/decline` | 辞退（コーチ） |
| `POST /v1/support-consults/{id}/ask` | 聞き直し（コーチ） |
| `POST /v1/support-consults/{id}/propose` | 提案（コーチ） |

期限切れ（コーチが48時間返事をしなかった相談、有効期限が過ぎた提案）は、`/internal/coaching/tick` が閉じます（保護者に送ったあとの提案も同じ）。

## 仕組み上の注意

- 契約は既存の `coaching_contracts` を使います。契約には `plan_id` が必要なため、コーチごとに1つ、一覧に出ない入れ物のプラン（`coaching_plans.consult_template`）を持ちます。プラン管理の一覧・10個の上限・公開の一覧には入れません。契約の期間・価格・内容は提案の写しです。入れ物のプランは公開のままなので、既存の大会までプランの公開・下書きとは別に数えます。
- 入れ物のプランは公開のままにします（公開を切り替えると、特商法の表記の承認が外れるため）。コーチは「特商法・身元」で、このプランの表記を承認すると、選手側に入口が出ます。
- 入れ物のプランの契約は、プランの同時人数の上限（`capacity`）で数えません。
- 相談の質問項目は `apps/api/internal/httpx/support_consult.go` と `apps/web/lib/support-consult.ts` で合わせています。

マイグレーションは `000149`（up/down）、SQLは `apps/api/queries/support_consult.sql` です。
