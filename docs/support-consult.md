# 大会までプランの無料相談

大会までプランは、コーチが期間・価格を決めて出品する形ではなく、選手がコーチに**無料で相談してから**始まります。対面プランと動画添削には影響しません。

## 流れ

1. コーチが「相談の受付設定」（プラン管理）で、受付中か、担当する種目、相談で聞きたいこと・サポートできる内容、価格の目安（任意）を設定します。
2. 選手がコーチ詳細の「無料相談をする」から、構造化フォームで相談を送ります。支払いもカード情報の入力もありません。
3. コーチは **48時間以内** に提案か辞退を返します。フォームの回答だけでは分からないときは、フォーム形式で聞き直せます（1つの相談に3回まで。選手の答えが届いたら48時間を数え直す）。チャットにはしません。
4. 提案には、期間（開始日〜目標大会の日）、内容、価格（運営手数料20%を引いたコーチの受け取りも表示）、提案の有効期限が入ります。
5. 選手が提案を受けて申し込むと、既存のサポートプランの契約（コーチの返事待ち）になり、以降は従来の流れ（コーチの引受 → 未成年は保護者の同意 → カード支払い → 開始）に進みます。契約の中身は提案の写しで、終了日は目標大会の日です。
6. 申し込まなければ、そのまま終了します。契約も費用も生まれません。

進行中の相談や契約がないコーチには、次の大会向けにもう一度相談できます（回数制限なし）。新しい大会は、新しい相談・提案・契約として扱い、未成年は契約のたびに保護者の同意とお支払いを経ます。

## 受け入れ状況

人数の上限（受け入れ枠）は置きません。受け入れ状況は、コーチの対応可能カレンダーだけで決まります。

- 今日が「不可」の日 → 選手側に「受付停止中」（再開の目安つき）。新しい相談は送れません。
- 開始希望日が「不可」の日 → その日を開始日にした相談は送れません。
- 閉じた期間が終われば、コーチの操作なしに「受付中」に戻ります。
- 契約件数や残り枠は、選手側に表示しません。

## API

| メソッド・パス | 内容 |
| --- | --- |
| `GET /v1/coaches/{id}/support-consult` | 公開の入口と受け入れ状況。受け付けていなければ `consult: null` |
| `GET/PUT /v1/coach/me/support-consult` | 受付設定（コーチ本人） |
| `GET /v1/coach/me/support-consults` | 届いた相談（コーチ本人） |
| `POST /v1/support-consults` | 相談を送る（選手） |
| `GET /v1/me/support-consults` | 自分が送った相談 |
| `GET /v1/support-consults/{id}` | 相談の詳細（当事者のみ） |
| `POST /v1/support-consults/{id}/answer` | 聞き直しへの答え（選手） |
| `POST /v1/support-consults/{id}/withdraw` | 取り下げ（選手） |
| `POST /v1/support-consults/{id}/accept` | 提案を受けて申し込む（選手）。契約ができる |
| `POST /v1/support-consults/{id}/decline` | 辞退（コーチ） |
| `POST /v1/support-consults/{id}/ask` | 聞き直し（コーチ） |
| `POST /v1/support-consults/{id}/propose` | 提案（コーチ） |

期限切れ（コーチが48時間返事をしなかった相談、有効期限が過ぎた提案）は、`/internal/coaching/tick` が閉じます。

## 仕組み上の注意

- 契約は既存の `coaching_contracts` を使います。契約には `plan_id` が必要なため、コーチごとに1つ、一覧に出ない入れ物のプラン（`coaching_plans.consult_template`）を持ちます。プラン管理の一覧・10個の上限・公開の一覧には入れません。契約の期間・価格・内容は提案の写しです。
- 入れ物のプランは公開のままにします（公開を切り替えると、特商法の表記の承認が外れるため）。コーチは「特商法・身元」で、このプランの表記を承認すると、選手側に入口が出ます。
- 入れ物のプランの契約は、プランの同時人数の上限（`capacity`）で数えません。
- 相談の質問項目は `apps/api/internal/httpx/support_consult.go` と `apps/web/lib/support-consult.ts` で合わせています。

マイグレーションは `000149`（up/down）、SQLは `apps/api/queries/support_consult.sql` です。
