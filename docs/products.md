# レビュータブの商品の運用

商品は運営が管理画面(`/admin` の「商品」タブ)から追加・更新する。

## 商品を追加する

1. ブランド・商品名を入力する(同じブランド+商品名は大文字小文字を無視して重複扱いになる)。
2. 画像は `apps/web/public/products/` に置き、画像URLには `/products/xxx.png` のように書く。外部の画像を使う場合は `https://` から始める。
3. 公式ページURLは、ブランドの公式サイトの商品ページを `https://` から貼る。空のときは詳細ページにリンクが出ない。
4. 登録した商品は、一覧の「レビューが多い順」の中に入る。

## 新作が出たとき

- ユーザーからの「追加をリクエスト」は、管理画面の「商品リクエスト」タブに届く。ブランド・商品名・公式URLが本文に入っているので、確認して商品に追加する。
- 追加したあと、リクエストへの返信は不要(返信先メールアドレスは受け取らない)。

## 型落ちになったとき

- 「商品」タブの各行で「旧モデル」にチェックして保存する。
- レビューは消えず、一覧では新しい商品の後ろに並び、「旧モデル」と表示される。
- 間違って登録した商品だけ「非表示」にする(一覧から消える)。

## 既存商品の公式ページURL

migration 000037 では URL を空のままにしている。管理画面の各行から1件ずつ入れていく。
