# レビュータブの商品の運用

商品は運営が管理画面(`/admin` の「商品」タブ)から追加・更新する。

## 商品を追加する

1. 種類（シューズ／スパイク）を選び、ブランド・商品名を入力する(同じブランド+商品名は大文字小文字を無視して重複扱いになる)。
2. 画像URLは任意。登録する場合は `https://` から始まる500文字以内のURLを使う。`/products/xxx.png` のような相対URLはAPIが受け付けない。静的画像を `apps/web/public/products/` に置く場合も、公開先のHTTPSの完全なURLを入力する。
3. 公式ページURLは、ブランドの公式サイトの商品ページを `https://` から貼る。空のときは詳細ページにリンクが出ない。
4. 登録した商品は、選択した種類の一覧に入る。旧モデルでない商品を先にし、その中をレビュー件数、平均評価、登録日時の降順で並べる。

## 新作が出たとき

- ユーザーからの「追加をリクエスト」は、管理画面の「商品リクエスト」タブに届く。ブランド・商品名・公式URLが本文に入っているので、確認して商品に追加する。
- 追加したあと、リクエストへの返信は不要(返信先メールアドレスは受け取らない)。

## 型落ちになったとき

- 「商品」タブの各行で「旧モデル」にチェックして保存する。
- レビューは消えず、一覧では新しい商品の後ろに並び、「旧モデル」と表示される。
- 間違って登録した商品を「非表示」にすると一覧から消える。現在の編集欄は公式ページURLと旧モデルの切替で、ブランド・商品名・画像の変更や非表示の解除の操作はない。

## 既存商品の公式ページURL

マイグレーション `000037` は公式ページURLを空で追加する。URLが未登録の商品は、管理画面の各行から1件ずつ入力して保存する。空のままなら詳細ページに公式リンクを出さない。
