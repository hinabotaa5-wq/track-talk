# 法務まわりの下書き（たたき台）

弁護士の無料Q&A（ココナラ・弁護士ドットコム）と関東総合通信局の回答をもとにした初期方針の下書き。
**どれも確定した文面ではない。** 本番の `/terms` などには、弁護士の確認と、ひなたさんの判断を経てから入れる。
「要確認」と書いた欄は、資金決済法の回答（投稿3）で覆りうるので、本番の文面が決まるまで外さない。

## 1. 利用規約に足す「当事者の立場」（下書き）

根拠: ココナラ回答1（(1)動画添削は運営者が契約の相手方、(2)サポートプランはコーチが契約の相手方）。
弁護士ドットコム回答1は「仲介にするか、運営者が間に入るかは設計次第。立場をサイト上に明示すること」という一般論。

> **第○条（取引の相手方）**
> 1. フォーム添削、チケット、フォーム添削の追加相談は、運営者が利用者に販売します。運営者は、承認したコーチに添削の業務を委託します。
> 2. サポートプラン（動画添削・大会サポート・対面指導などを含むコーチのプラン）は、プランを出しているコーチが利用者に販売します。運営者は、申し込みの場を提供します。
> 3. 代金の受け取りと、コーチへの支払いの方法は、別に定めます。（要確認: 資金決済法の回答待ち。収納代行・Stripe Connect での直接の支払いのどちらで書くかが決まっていない）

画面では、購入の前に `SellerNote`（`apps/web/components/seller-note.tsx`）で販売者を1行で示す。

## 2. 特定商取引法に基づく表記

- 運営者の分（(1)用）: `apps/web/app/legal/commerce/page.tsx`。`NEXT_PUBLIC_COACHING_ENABLED` が空の間は 404。
  - 所在地・電話番号は「請求があれば遅滞なく開示します」で省略する（ココナラ回答1の省略方法①）。実際に速やかに開示できる体制が前提。
  - 開示請求は、お問い合わせの種類「特商法表記の開示請求」（`disclosure`）か、メールで受け付ける。
  - 支払方法・チケットの有効期限・未使用分の返金は「要確認」。
- コーチの分（(2)用）: まだ無い。コーチごとの表記（原則フル表記、表記要否のフラグ）は別の PR で作る。

## 3. 有料の1対1のやりとり

根拠: 関東総合通信局の回答（有料の1対1メッセージは電気通信事業の届出の対象。始める前に届出が必要で、受理まで約2〜4週間）。
`COACHING_MESSAGING_ENABLED` / `NEXT_PUBLIC_COACHING_MESSAGING_ENABLED` を、届出が受理されるまで空にしておく。

## 4. 取引条件の通知（フリーランス保護法3条）

根拠: 弁護士ドットコム回答2（運営者→コーチは業務委託。無雇用の個人事業主は特定業務委託事業者にあたらないので
60日以内の支払義務は不適用、3条の明示だけ必要。利用規約への同意だけでは足りず、案件ごとの明示が要る）。

- 対象は、運営者が販売する **(1) フォーム添削と、その追加相談だけ**。打診の画面で引き受ける前に9項目を見せ、
  引き受けたら `coach_work_orders` に書き留める（後から書き換えない）。文面は `apps/api/internal/httpx/work_order.go`。
- **(2) サポートプランへの拡張は、弁護士の回答（Q9）の後に決める。** 回答2は「(1)と(2)で違うかは商流が分からず答えられない」で、
  (2)に通知が要らないとは言われていない。
- 未確定: 支払期日の書き方（3,000円未満の繰り越しがあると1つの日付に決まらないため、「翌月15日、繰り越したら翌々月15日」と
  両方を書いている。Q6）と、画面での表示と記録で「電磁的方法による明示」として足りるか（メールも送るべきか。Q7）。
- 検査の欄は「検査をしない（送信した時に受け取ったものとする）」と仮に書いている。運営者が非表示にする運用との関係は要確認。
