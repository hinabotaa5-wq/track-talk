# 動画添削：選手がコーチを選ぶ方式

動画添削の申込みは `/coaching/new` に統一する。選手は種目を選び、その種目で受付中のコーチの中から1人を選んで動画を送る。運営がコーチを割り振る「おまかせ」は止めた（`REVIEW_RANDOM_ASSIGN_ENABLED` を空のまま）。商品名は「動画添削」のまま。

## 料金と報酬

- 1,500円／動画1本。どのコーチを選んでも同じ（コーチごとの価格差はつくらない）。コーチの報酬は70％（1,050円）、運営の取り分は30％（450円）。
- 申込み時に選んだコーチ・名前・料金（`base_price_yen`）を依頼に保存し、その後の料金変更は反映しない。
- 以前あったコーチごとの指名料は廃止し、DB の列も `000124_review_drop_nomination_fee` で消した。
- 追加相談は600円・報酬70％のまま。購入済みチケットは2枚で動画添削1本に使える（新規販売は終了）。

## 選べるコーチと並び順

- 承認済み・受付中で、担当種目が合い、同時に持てる依頼（2本）と1日の上限（コーチが設定）に届いておらず、報酬口座の登録が済んでいるコーチ。評価が低く順番から外れているコーチと、自分自身は出ない。
- コーチ側の調整は、価格ではなく受付のオン・オフと1日の上限で行う。
- 一覧に出すのは名前・顔写真・担当種目・競技歴・記録・紹介文（成績や指導経験）だけ。添削の件数・評価・売上・順位・バッジは出さない。
- 並び順は日替わり（コーチの ID と今日の日付のハッシュ順、`ListReviewNominees`）。同じ日は同じ順で、日が変わると入れ替わる。人気や実績では決めない。

## 申込み→支払い→依頼→添削→追加相談

1. 申込み（`POST /v1/coaching/requests`、`requested_coach_id` 必須）。この時点で担当コーチが決まっている。
2. 支払い（Stripe Checkout）。カードは仮押さえ、PayPay はその場で決済。支払い前はコーチに届かない。
3. 契約は申込み時に成立し、決済を確認すると依頼がコーチの対応中一覧に入る。チケットの場合は確保と同じトランザクションで割り当てる。
4. コーチは動画と内容を確認し「添削をはじめる」を押してから入力する。添削の返却でカードを確定し、報酬を記録する。
5. 返却後の追加相談は、担当した（選んだ）コーチとの間で従来どおり。

## コーチが対応できないとき

- 着手前の選手キャンセル、例外返却、または24時間の返却期限切れで終了する。カードの仮押さえを取り消し、PayPayは全額を返金し、チケットは1枚返す。
- 返却期限（申込みから24時間。夜間も止まらない）までに返らなかった依頼も同じく終了・返金する。
- 動画が見えるものの相談内容が不明な場合は、1回だけ補足を求められる。選手は24時間以内に再提出し、返却期限は再提出から24時間に更新される。
- 動画が見えない、競技・種目違い、医療上の判断を求める内容などの場合は、コーチが期限内に理由を選んで例外返却する。任意メモを保存できる。
- 期限の計算は `apps/api/internal/httpx/review_deadline.go`（2026-11-02 の運営者決定で、旧「翌日の正午」から変更）。

## おまかせ（割り当て）を止めている仕組み

- `REVIEW_RANDOM_ASSIGN_ENABLED` が空の間、コーチを選ばない申込みは 422（`requested_coach_id`）。割り当て処理（`offerReview` の `PickCoachForRequest`）はコーチを選んでいない依頼を誰にも回さない。辞退・時間切れ・コーチの退会のあとも別のコーチには回さない。
- 割り当てのコード・`review_offers` などの過去の打診・割り当ての記録は消していない。再開するときはフラグを立てる（申込み画面には「おまかせ」の選択肢がないので、画面も戻す必要がある）。

## サポートプラン

新規作成・公開一覧・新規申込みから `video_review` のサポートプランを外したまま。大会サポートと対面指導を表示する。旧動画プランや契約の履歴は削除しない。
