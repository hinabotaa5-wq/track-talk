# 動画添削の指名オプション

動画添削の申込みは `/coaching/new` に統一する。初期状態はおまかせで、任意の「コーチを選んで指名料を追加する」を開いた場合だけ、同じページでコーチを選ぶ。

- 基本料金は1,200円／動画1本。指名料はコーチが100円単位で設定。空欄は指名受付なし、0円は無料指名。
- 指名候補は承認済み・受付中で、種目、評価、同時受付数、日次上限、報酬口座の条件を満たすコーチ。自分自身は選べない。
- 指名料を含めた合計を送信前に表示。申込み時に指名先、名前、基本料金、指名料を保存し、その後の価格変更は反映しない。画面で確認した指名料とサーバーの値が異なる場合は申込みを拒否する。
- 基本料金のチケット2枚と、指名料のカード・PayPay決済を併用可能。指名料の支払い前はコーチへ打診しない。
- 指名先への打診は既存と同じ30分。辞退・打診時間切れで終了し、別コーチへ再割当てしない。回答期限までに提供されなかった依頼も終了する。
- 成立しなかった依頼はチケットを返却し、カードの仮押さえを取り消すかPayPayを返金する。処理は定期精算で再試行される。支払いを放置した依頼は従来どおり2時間後に整理し、チケットを戻す。
- コーチ報酬は基本料金の70％＋指名料の80％。チケットのまとめ買い割引は運営負担。指名料を含む報酬は決済確定後に記録する。
- 回答内容と追加相談は既存の動画添削の仕組みを使う。指名料だけで無期限の相談や定期メニュー作成を約束する仕様ではない。

## サポートプラン

新規作成・公開一覧・新規申込みから `video_review` のサポートプランを外す。大会サポートと対面指導を表示する。大会サポートに含まれる動画確認は引き続き利用できる。

旧動画プランや契約の履歴は削除しない。既存契約は保存済みの条件で継続し、旧プランは管理画面から非公開にできる。既存料金を指名料に自動変換しない。分類が未設定の旧プランは従来の互換動作を維持する。

## 公開時

APIを切り替える前に `000118_review_nomination` のDB移行を適用する。既存のコーチング公開フラグは変更しない。公開前にコーチが指名料を設定する。今回の変更は本番デプロイを含まない。
